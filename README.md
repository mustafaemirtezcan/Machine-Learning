# 🧑‍💻Machine Learning

Machine learning assignments as Jupyter notebooks, going from a hand-written perceptron to deep learning.

- **PA1 - Perceptron:** Binary classification with a perceptron written from scratch, with decision boundary visualizations.
- **PA2 - SVM and Logistic Regression:** Linear and kernel SVMs tuned with grid search on the Sonar dataset, and multinomial logistic regression on Dry Beans.
- **PA3 - CNNs:** A CNN built from scratch for 15 vegetable classes, compared with fine-tuned ResNet18 and MobileNet (Kaggle scores of 0.973, 0.995 and 0.997).
- **PA4 - LSTM:** Sentiment analysis on IMDB reviews with a custom LSTM and pretrained word embeddings.

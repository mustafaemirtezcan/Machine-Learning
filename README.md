# 🧑‍💻 Machine Learning

From a hand-written perceptron to deep learning 🤖, all in Jupyter notebooks.

- 📐 **PA1 - Perceptron:** Binary classification with a perceptron written from scratch.
- 🫘 **PA2 - SVM & Logistic Regression:** Classifying sonar signals and dry bean varieties.
- 🥦 **PA3 - CNNs:** Recognizing 15 kinds of vegetables. A CNN built from scratch is compared with fine-tuned ResNet and MobileNet, which reached up to 0.997 on Kaggle.
- 🎬 **PA4 - LSTM:** Sentiment analysis on IMDB movie reviews.
